# Portfolio

Personal portfolio site showcasing work as a Creative Technologist, focused on blending design, frontend development, and real-world systems thinking.

## Built With

- React + Vite
- Modern CSS (Grid, Flexbox, responsive layout)
- Lucide Icons

## Features

- Responsive carousel with adaptive layout (3 / 2 / stacked)
- Data-driven components rendered from structured JSON
- Modular card and modal architecture
- Mobile-first fallback to stacked layout

## Status

This portfolio is actively evolving. Additional projects and detailed case studies will be added soon.
